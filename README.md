# Banco Imobiliário — PWA v4

Versão touchscreen, offline-first e preparada para GitHub Pages.

## Instalação no iPhone
1. Publique no GitHub Pages.
2. Abra a URL no Safari.
3. Compartilhe → Adicionar à Tela de Início.
4. Abra pelo ícone criado.

O site usa HTTPS no GitHub Pages e o service worker permite o uso offline depois do primeiro carregamento.
